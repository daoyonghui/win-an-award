# PrintMind 现场演示兜底方案

比赛现场网络与第三方 API 存在不确定性。本文覆盖三种场景，确保**任何情况下都能完成核心展示**。

---

## 场景 A：DeepSeek API 正常（完整演示）

**状态**：`backend/.env` 已配置 `DEEPSEEK_API_KEY`，网络可访问 `https://api.deepseek.com`。

**演示路径**：

1. 进入「智能诊断」
2. 上传固定测试图片（见 `docs/demo_assets.md`）
3. 填写固定参数（当前候选参数）
4. 运行诊断
5. 展示：
   - 缺陷诊断结果（缺陷 / 严重程度 / 置信度）
   - 图片视觉证据（模型给出的图像证据）
   - 历史实验经验（已参考真实实验条数、改善/恶化参数）
   - 最小改动参数推荐
   - 推荐依据
6. 进入「历史记录」查看系统闭环验证结果

**话术**：这是图像 + 工艺参数的多模态诊断，推荐来自真实实验经验，而不是固定规则。

---

## 场景 B：DeepSeek API 不可访问（规则回退）

**状态**：无 Key、Key 失效、超时或网络受限。

**系统行为（已实现，无需操作）**：

- 视觉调用失败会被安全捕获，**不会导致接口报错**；
- 自动回退到 PETG 规则诊断；
- 页面【注意事项】提示：视觉分析不可用，已回退到工艺参数规则诊断；
- **历史实验经验、最小改动推荐、推荐依据仍然完整展示**（这些来自本地 SQLite，不依赖外部 API）。

**演示路径**：与场景 A 相同，仅“图片视觉证据”区域显示回退提示。

**话术**：即使视觉 API 不可用，系统也会自动降级为规则诊断，本地实验经验与参数推荐不受影响——这正是工程上的稳健性设计。

> 提示：如需完全避免现场等待，可提前在无网络环境下演练一次，确认回退提示与后续模块正常。

---

## 场景 C：网络完全不可用（离线展示）

**状态**：现场无网络（前端与后端仍在本机运行）。

**仍可完整展示**：

| 展示项 | 说明 |
| --- | --- |
| 首页 | 项目介绍、系统工作流程、核心能力、实验成果摘要 |
| 实验结论总览 | 核心指标、质量趋势图、实验时间线、系统学习过程、候选参数、实验结论 |
| REAL-001～REAL-009 | 全部来自本地 SQLite |
| 质量趋势 | 原生 SVG 折线图 |
| 历史闭环记录 | `GET /history`、`GET /history/{id}` |
| 实验图片 | REAL-006/007/008/009 图片经本地 `/uploads` 提供 |
| 已保存诊断结果 | 历史记录详情页 |

**不可用项**：仅“上传新图片后的视觉分析”（需要 DeepSeek API）。

**演示路径建议**：

```
首页 → 实验结论总览（重点讲趋势与结论）→ 历史记录 → 打开 REAL-006 闭环详情
```

**话术**：核心实验结论与闭环验证结果全部保存在本地数据库，现场即使没有网络，也能完整展示真实实验结果。

---

## 现场快速检查清单

1. 双击 `check_printmind.bat`，确认输出「PrintMind 比赛环境检查通过」。
2. 双击 `start_printmind.bat` 启动前后端。
3. 打开 http://127.0.0.1:5173，先走一遍「实验结论总览」。
4. 若现场网络不稳，直接按**场景 C** 演示（无需联网）。

---

*原则：优先保证核心实验结果与闭环验证可展示；视觉 API 仅作为增强项。*
