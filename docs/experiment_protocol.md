# PrintMind 实验规范（Experiment Protocol）

本规范用于 PrintMind 在 Bambu Lab P1S + PETG 上的真实打印实验，
确保诊断与优化结果可追溯、可复现、可用于比赛答辩展示。

---

## 1. 实验记录字段（每次真实实验必须完整记录）

| 序号 | 字段 | 说明 |
| --- | --- | --- |
| 1 | 实验编号 | 唯一编号，例如 `PM-2026-001` |
| 2 | 日期 | 实验日期（YYYY-MM-DD） |
| 3 | 打印机 | 例如 Bambu Lab P1S |
| 4 | 材料 | 例如 PETG（品牌/颜色可注明） |
| 5 | 模型名称 | 打印模型名称或文件 |
| 6 | 喷嘴温度 | 优化前实际使用值（℃） |
| 7 | 热床温度 | 优化前实际使用值（℃） |
| 8 | 打印速度 | 优化前实际使用值（mm/s） |
| 9 | 风扇 | 优化前实际使用值（%） |
| 10 | 层高 | 优化前实际使用值（mm） |
| 11 | 回抽 | 优化前实际使用值（mm） |
| 12 | 原始图片 | 优化前打印件照片（清晰、光线充足） |
| 13 | PrintMind 诊断 | 缺陷类型、严重程度、置信度、可能原因 |
| 14 | 推荐参数 | 系统给出的优化后参数 |
| 15 | 优化后图片 | 使用推荐参数重新打印后的照片 |
| 16 | 优化前评分 | 人工质量评分（0~100） |
| 17 | 优化后评分 | 人工质量评分（0~100） |
| 18 | 是否改善 | 是 / 否 |
| 19 | 备注 | 观察记录、环境条件、异常情况等 |

> 建议统一评分口径（例如同一评价者、同一评价标准），保证 before/after 可比。

---

## 2. 数据来源约定

- `data_source = real`：真实打印实验数据，可计入比赛统计。
- `data_source = simulated`：用于功能演示与开发测试的数据。

**明确要求：**

> 模拟数据只能用于功能演示和开发测试，
> 不能作为真实实验结果参与比赛效果统计。

PrintMind 的 `GET /stats` 默认只统计 `real` 数据；
只有显式传入 `include_simulated=true` 时，才会包含 `simulated` 数据。
任何 `simulated` 记录都不得计入默认比赛统计。

---

## 3. 闭环流程

```
打印 → 拍照 → PrintMind 诊断 → 获得推荐参数
     → 使用推荐参数重新打印 → 拍照 → 填写优化后评分
     → 记录“是否改善” → 归档（real）
```

---

## 4. 统计口径

- 累计真实诊断：`data_source = real` 的诊断记录数
- 已完成真实优化验证：`real` 且 `verified = 1` 的记录数
- 改善案例数：`real`、`verified = 1` 且 `defect_improved = 1` 的记录数
- 优化改善率：改善案例数 / 已完成真实优化验证数（无数据时为 0）
- 平均质量评分：对 `verified = 1` 的记录取 `quality_before` / `quality_after` 均值
- 平均质量提升：对同时具备前后评分的已验证记录取 `quality_after - quality_before` 均值

所有数值均来自 SQLite 真实记录，系统不编造、不自动生成“成功率”。
