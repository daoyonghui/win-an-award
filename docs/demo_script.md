# PrintMind 演示脚本（3～5 分钟）

> 目标：评委在 3～5 分钟内看懂“真实设备 + 真实实验 + 闭环优化 + 可解释推荐”。

---

## 0:00–0:30 首页介绍

- 打开 http://127.0.0.1:5173
- 主标题：**PrintMind** — 基于多模态智能体与工艺闭环优化的 FDM 3D 打印质量控制系统

**话术**：

> FDM 打印参数调整长期依赖经验，缺陷原因难以解释。PrintMind 用打印图像 + 工艺参数做缺陷诊断，结合真实实验经验给出“最小改动”的优化建议，并通过再次打印完成闭环验证。

---

## 0:30–1:20 实验结论总览

- 点击「查看实验结论总览」

**展示重点**：

- 核心指标：基准 **65**、正式闭环 **65 → 78**、最高实验评分 **85**、重复性实验 **3** 次
- 质量趋势图：REAL-001 ～ REAL-009
- 实验时间线：
  - REAL-001 基准组
  - REAL-002 / REAL-003 单变量实验（降温 / 提高回抽）
  - REAL-004 重复性验证
  - REAL-005 单变量实验（增强风扇）
  - **REAL-006 系统闭环验证（65 → 78）**
  - REAL-007 / REAL-008 重复性验证（85 / 80）
  - REAL-009 进一步参数探索（77）

**话术**：

> 这是一条真实实验链：基准 65 分；系统采用最小改动策略做闭环验证后提升到 78；相同推荐参数重复打印达到 85 和 80；继续加大风扇没有继续提升，说明 40–60% 在当前实验条件下更合适。

---

## 1:20–2:40 智能诊断

- 返回首页 → 点击「开始智能诊断」
- 上传固定测试图片（见 `docs/demo_assets.md`）
- 填写固定参数（当前候选参数）：
  - nozzle_temp = 245，bed_temp = 70，outer_wall_speed = 60，fan = 40–60，layer_height = 0.16，retraction = 0.8
- 点击「开始诊断」，观察流程状态：分析图像 → 分析工艺参数 → 生成优化方案 → 诊断完成

**话术**：

> 现场用一张真实打印件照片，配合当前工艺参数运行诊断。

---

## 2:40–3:40 展示诊断结果

按页面顺序讲解：

1. **缺陷诊断结果**：缺陷类型、严重程度、综合置信度
2. **图片视觉证据**：模型给出的图像证据（若视觉不可用则说明已回退规则诊断）
3. **历史实验经验**：已参考真实实验条数、改善趋势参数、曾恶化参数
4. **参数优化建议**：最小改动策略提示 + 当前 vs 推荐参数表
5. **推荐依据**：历史实验依据 + 工艺风险评分 + “本轮优先调整 X，其余保持不变”
6. **注意事项**：条件限定与复核提示

**话术**：

> 推荐不是拍脑袋：历史实验显示增强冷却有改善趋势，降温和提高回抽曾恶化，所以本轮只调整一个参数、其余保持——这就是最小改动策略。

---

## 3:40–4:30 历史闭环验证

- 进入「历史记录」
- 打开 **REAL-006**（系统闭环验证）详情：
  - 第一次打印（原图 + 原参数 + 缺陷诊断）
  - 系统推荐
  - 系统优化验证（65 → 78，已改善）
  - 优化结果

**话术**：

> 这是闭环的落点：按推荐参数再打印后，质量由 65 提升到 78，结果回写数据库并进入经验学习。

---

## 4:30–5:00 总结

**四点收尾**：

1. **真实设备**：Bambu Lab P1S + Bambu PETG HF（红色，0.4 mm）
2. **真实实验**：REAL-001 ～ REAL-009 全部真实打印
3. **闭环优化**：推荐 → 再打印 → 评分 → 回写
4. **可解释推荐**：视觉证据 + 风险评分 + 历史实验依据

> 结论限定在“当前实验条件下”，不夸大统计显著性。
