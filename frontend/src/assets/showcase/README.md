# Showcase images

把精品 3D 打印成品图片（jpg / jpeg / png / webp）放入本目录，首页 Hero 会自动显示。

推荐命名（按顺序）：

- `showcase-hero.jpg` — 首页 Hero 主视觉（必需，第一张）
- `showcase-2.jpg` — 备用
- `showcase-3.jpg` — 备用

要求：

- 图片应为**完整、精致、干净**的成品（花瓶、几何艺术件、机械结构件、关节模型等）。
- 请勿使用拉丝 / 翘边 / 欠挤出的失败件作为首页主视觉。
- 目录为空时，首页会显示优雅的占位块，不会报错。
- 不修改 `data/uploads` 中的真实实验图片。

Add high-quality finished-print photos here; the homepage hero loads them automatically.
